Politique de confidentialité

Saytu Xalis - Application de gestion de budget

Date d'effet : 5 août 2026

1. Données collectées

Saytu Xalis collecte les données suivantes pour fournir ses services :

  • Informations de compte : email ou numéro de téléphone, nom, mot de passe (chiffré)
  • Données financières : revenus, dépenses, budgets saisis par l'utilisateur
  • Préférences : thème, paramètres de notifications

Nous ne collectons aucune donnée bancaire, numéro de carte, ou information de paiement.

2. Utilisation des données

Vos données sont utilisées exclusivement pour :

  • Fournir les fonctionnalités de l'application (suivi de budget, prédictions)
  • Sauvegarder et restaurer vos données via le cloud
  • Améliorer l'expérience utilisateur

3. Stockage et sécurité

Vos données sont stockées localement sur votre appareil et sauvegardées de manière sécurisée dans le cloud. Les mots de passe sont chiffrés avec bcrypt. Les communications sont protégées par HTTPS.

4. Publicités

Saytu Xalis utilise Google AdSense pour afficher des publicités. AdSense peut collecter des identifiants publicitaires et des données d'utilisation anonymisées conformément à la politique de confidentialité de Google.

5. Partage des données

Nous ne vendons, ne partageons et ne transmettons vos données personnelles à aucun tiers, sauf :

  • Google AdSense (données anonymisées pour la publicité)
  • Si requis par la loi

6. Vos droits

Vous pouvez à tout moment :

  • Supprimer toutes vos données depuis les paramètres de l'application
  • Supprimer votre compte en nous contactant
  • Exporter vos données en format CSV

8. Modifications

Cette politique peut être mise à jour. Les modifications seront publiées sur cette page avec une nouvelle date d'effet.
